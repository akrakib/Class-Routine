# 📚 About Class Routine

**Class Routine** is a simple and lightweight Android application designed to help students easily view and manage their class schedules.

The goal of this project is to make checking class times and schedules faster, easier, and more organized.

---

## ✨ Features

- 📅 Easy class schedule viewing
- ⏰ Check class times quickly
- 📚 Organize subjects and classes
- 📱 Simple and clean interface
- ⚡ Lightweight and fast
- 🎓 Designed for students
- 🚀 Easy to use
